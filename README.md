# SimpleERP Frontend

This is the frontend application for SimpleERP, built using Angular (Standalone Components).

## Features

- **Admin Layout**: Responsive dashboard layout with sidebar and top navigation.
- **Employee Management**: View, add, edit, delete employees. Pagination and department filtering supported.
- **Department Management**: Manage company departments.
- **Attendance Tracking**: View daily employee check-ins and late/early leave penalties.
- **Authentication**: Login, Register, Forgot Password, and Role-based Route Guards.

## Tech Stack

- Angular 
- Standalone Components
- Signals (for reactive state)
- HttpClient (with interceptors for auth & error handling)
- Custom CSS (CSS Variables, Flexbox, Grids)

## Setup and Running

1. Run `npm install` to install dependencies.
2. Run `ng serve` to start the development server.
3. Navigate to `http://localhost:4200/`.

Ensure the SimpleERP.API backend is running at `http://localhost:5188` to fetch data.
